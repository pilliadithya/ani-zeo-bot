# Ani Zeo Bot

Ani Zeo is an AI-powered anime companion that helps users discover anime, manage watchlists, and receive personalized recommendations.

## Features

- Anime search
- Personalized recommendations
- Watchlist management
- User profiles
- AI-powered responses
- Telegram bot support

## Tech Stack

- Python
- TypeScript
- Node.js
- JSON
- Replit
