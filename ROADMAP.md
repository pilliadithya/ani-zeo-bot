# Ani Zeo Roadmap

## Version 0.8 (Released) ✅
- /genre — Browse top anime by genre

## Version 0.9 (Released) ✅
- /season — Top airing anime this season with date
- /airing — Anime airing today by schedule

## Version 1.0 (Released) ✅
- /character — Top 5 main characters for any anime
- /studio — Studio name, type, and anime count
- Improved /help with grouped command categories

## Version 2.0 (Released) ✅
- AniList GraphQL integration (richer data across all commands)
- Interactive Reply Keyboard menu
- /search with poster image, enhanced details, and streaming platforms
- /trending — top trending anime via AniList
- /news — latest airing anime updates with episode countdowns
- /trailer <anime> — official YouTube trailer link
- /compare <a> vs <b> — side-by-side anime comparison
- /schedule <day> — airing anime by day of week
- /quiz — 15-question anime trivia with inline buttons
- /favorite add/remove, /favorites — personal favourites (persisted)
- /character and /studio upgraded to AniList

## Version 2.1 (Released) ✅
- /beginner — newcomer guide to anime
- /starterpack — 10 essential anime to start with
- /recommend <anime|genre> — smart recommendations
- /order database expanded to 29 franchises with 80+ aliases
- Genre deduplication across all results

## Version 3.0 — Ultimate Anime Companion (Released) ✅
- **Watchlist system**: /watchlist add/remove/watching/completed/planned/dropped
- **User profiles**: /profile and /stats with activity tracking
- **Manga system**: /manga, /topmanga, /randommanga, /mangagenre (18 genres)
- **Dub info**: /dub — voice acted languages per title via AniList
- **Upcoming anime**: /upcoming — most anticipated next-season releases
- **Enhanced /character**: Japanese + English voice actors per character
- **Enhanced /genre**: 10 randomised results, fresh every time
- **Enhanced /search**: prequel/sequel relations + profile tracking
- **Enhanced /recommend**: 10 results, "anime like X" pattern support
- **Enhanced /order**: lists all 37 franchises on no-args, better fallback
- 33 total commands
